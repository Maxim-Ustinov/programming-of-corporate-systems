## 🛠 Реализация и Использованные Виджеты

Практическая часть работы заключалась в создании простого экрана, который демонстрирует ключевые концепции Flutter UI.

### 1. Древовидная структура и Базовые Виджеты

Интерфейс был построен на основе древовидной структуры виджетов, начиная с runApp() и `MaterialApp`.

* `Scaffold`: Использовался как базовый шаблон страницы для организации верхней панели (AppBar) и основного содержимого (body).
* `AppBar`: Реализована верхняя панель приложения с заголовком "Практика 3".
* `Center`: Применен для центрирования всего содержимого экрана.
* `Text("Hello world")`: Отображает строку текста. Текст был изменен на "Hello world".
* `ElevatedButton`: Реализована кнопка с заливкой.
* `Container`: Использовался для создания универсального блока с заданными размерами, цветом и внутренним текстом.
* `Icon`: Две иконки использованы для демонстрации горизонтальной компоновки.

### 2. Компоновка Элементов (Layout)

Для организации элементов были использованы основные виджеты компоновки:

* `Column`: Главный виджет, используемый для вертикального расположения всех элементов. Применено свойство mainAxisAlignment: MainAxisAlignment.center для центрирования элементов по вертикали.
* `Row`: Использован внутри Column для горизонтального расположения двух виджетов `Icon`.
* `SizedBox`: Применен для создания фиксированных отступов между элементами.

### 3. Работа со Стилями и Цветами

Для придания элементам визуального стиля были использованы классы Color и TextStyle
